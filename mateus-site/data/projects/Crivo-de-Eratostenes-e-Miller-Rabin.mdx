## // Crivo de Eratóstenes e Miller-Rabin

Implementação em Python de dois algoritmos fundamentais para a identificação de números primos: o **Crivo de Eratóstenes** e o teste de primalidade de **Miller-Rabin**.

## // Motivação e Contexto (Otimização)

Este projeto foi concebido no âmbito de uma disciplina de otimização, o intuito era fazer um algoritmo simples de encontrar números primos mas eu quis ir além. O principal objetivo foi explorar como diferentes algoritmos voltados para a solução do mesmo problema.

## // Implementação

A implementação de ambos os algoritmos foi realizada em Python.

O **Crivo de Eratóstenes** tem duas grandes vantagens, ser determinísticos e retornar uma lista de números primos em um range determinado pelo usuário. Em contraste, o teste de primalidade de **Miller-Rabin** foi desenvolvido como uma solução de alta performance para verificar a primalidade de números extremamente grandes. Sendo um algoritmo probabilístico, ele fornece uma resposta rápida com uma margem de erro extremamente controlável, tornando-o indispensável para aplicações que lidam com números fora do alcance dos métodos determinísticos.
