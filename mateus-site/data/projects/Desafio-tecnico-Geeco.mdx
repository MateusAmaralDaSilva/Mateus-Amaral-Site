## // Desafio Técnico Geeco: Gestão Inteligente de Fornecedores

Desenvolvimento de um sistema *Full-Stack* voltado para o controle e a gestão inteligente de fornecedores, criado como parte de um desafio técnico para uma vaga de estágio.

## // Escopo e Arquitetura

O projeto exigiu a construção da aplicação de ponta a ponta. No *front-end*, utilizei **Next.js** para criar uma interface ágil, responsiva e moderna. No *back-end*, o trabalho focou-se na modelagem robusta dos relacionamentos do banco de dados (utilizando **PostGressSQL**) e na implementação de um sistema seguro de controle de usuários usando a autenticação do Supabase.


## // O Diferencial: Chatbot com Inteligência Artificial

Para elevar o nível técnico da entrega e acelerar a busca por informações, implementei um *chatbot* inteligente utilizando **Python** e a inteligência artificial generativa do **Google Gemini** por meio de context injection para que a inteligência artifical fosse capaz de trabalhar bem com os dados que já existiam, o context injection não é tão escalável como um RAG mas pelo tempo que eu tinha e pelo problema da empresa foi a opção ideal.

Esse assistente virtual foi desenhado especificamente para facilitar o dia a dia da equipe de compras. Em vez de o funcionário perder tempo a navegar por tabelas complexas ou a escrever consultas SQL, ele pode simplesmente fazer perguntas em linguagem natural ao *bot*. A IA interpreta o pedido e realiza as consultas no banco de dados, entregando respostas rápidas e precisas diretamente na interface do usuário.

## // Desafios

Havia muito tempo que eu não desenvolvia uma aplicação full stack então tive dificuldades principalmente no front-end (nunca tinha usado react), por isso o código ficou muito mal modularizado, entretanto estou usando next.js novamente nesse site e agora que aprendi com os erros do passado tenho um código muito mais robusto e conectado.
